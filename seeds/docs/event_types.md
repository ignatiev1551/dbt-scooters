### Types of user events (mapping dictionary)

This seed table serves as a reference for categorizing user events within our application.  
This table is essential for understanding user interactions and behaviors, as it maps unique  
event identifiers to their corresponding descriptive names. The data contained in this table is  
utilized by analysts and data scientists to analyze user engagement, track event occurrences,  
and derive insights into user behavior patterns.

The table is utilized in user behavior analysis: understanding how users interact with the application  
and identifying trends in event occurrences.
